# ✈️ SkyEnglish — Daily Goal-Oriented Aviation & Business English Platform

A modern, gamified web application tailored for aviation professionals and pilots preparing for international meetings, operational briefings, and English interviews.

---

## 🎯 Target Audience & Calibrated Baseline
* **Baseline Level:** TOEIC 875 / OPIc IH (Intermediate High)
* **Target Level:** OPIc AL / AM (Advanced Mid) & TOEIC 950+
* **Primary Focus:** Spoken fluency, executive boardroom diplomacy, and technical aviation terminology.

---

## 🚀 Key Features

### 1. Daily Goal-Oriented Dashboard (Anti-Chaos UX)
* **Circular Ring Progress Chart (SVG):** Visualizes daily completion at a glance.
* **Flame Streak Counter:** Tracks active daily study consistency.
* **Action-Oriented Task Cards:** 4 focused missions per day with bold CTA buttons and translucent completed states.
* **Psychological Safety:** Gentle "Catch Up" labels for incomplete past missions instead of failure tags.

### 2. Immersion Mode & Pomodoro Focus Zone
* **Focus Timer:** 25m, 15m, and 5m intervals with cumulative daily tracking.
* **Immersion Mode:** Distraction-free dark mode screen that hides all extraneous UI to keep you focused on speaking and writing.

### 3. Full 30-Day Day-by-Day Aviation Curriculum
30 curated real-world aerospace operational themes:
* Sustainable Aviation Fuel (SAF) blending limits & offtake agreements
* Airbus A350F composite freighters & global e-commerce supply chains
* Joby eVTOL FAA type certification & urban vertiport infrastructure
* Korean Air – Asiana Airlines merger, slot divestitures, and SkyTeam codeshares
* IATA One ID biometric boarding & decentralized identity
* Jet fuel price hedging, Pratt & Whitney MRO bottlenecks, and crisis communication

### 4. Interactive Oral Fluency Simulator
* Timed 90s – 150s impromptu speaking prompts
* Real-time browser speech recognition (Speech-to-Text)
* Suggested native transitional expressions & benchmark model answers

### 5. Option 4: 1-Click Aviation News Importer
* Paste any real-world aviation article or press release
* Automatically generates vocabulary cards, comprehension quizzes, and speaking discussion prompts

### 6. Real-Time Level Diagnostic Engine
* Real-time calculation of estimated OPIc level (IH $\rightarrow$ AL $\rightarrow$ AM), TOEIC projection, and CEFR benchmark
* 4-Pillar Competency Breakdown: Impromptu Speaking Velocity, Executive Writing Structure, Aviation Technical Lexicon, and Diplomatic Negotiation Tactics.

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Modern ES6+ JavaScript
* **APIs:** Web Speech API (SpeechRecognition)
* **Storage:** LocalStorage (zero cloud database required, 100% private)
* **Styling:** Custom responsive CSS grid & flexbox design with SVG graphics

---

## 💻 Quick Start

Simply clone and run any local HTTP server:

```bash
git clone https://github.com/aviation-safety/aviation_english.git
cd aviation_english
python3 -m http.server 8080
```

Open your browser at `http://localhost:8080`.
